# PC Matic Cancellation Guides — GitHub Pages

This package has 100 individual HTML guides under `articles/`, a minimal homepage, `style.css`, and `support.html`.

To publish: extract the ZIP, upload the files to the root of a GitHub repository, and enable GitHub Pages from the main branch root. Do not upload the ZIP itself as the website.

The site is independent and not affiliated with PC Matic. The cancellation help button opens the local support information page rather than an unverified third-party account portal.
